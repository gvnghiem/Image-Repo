# Image-Depot
This repo is to keep all the images I created or generated by ai.

**Gallery:** https://gvnghiem.github.io/image-depot/ (enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root)

## Folders
| Folder | Use |
|---|---|
| `icon/` | Logos, avatars, app/favicons |
| `photos/` | Photos and generated artwork |
| `thumbnails/` | Thumbnail-sized images you add yourself |
| `misc/` | Everything else |

## Adding images
Drop files into `icon/`, `photos/`, `thumbnails/` or `misc/` and push. A GitHub Action rebuilds `manifest.json` and the small previews in `_previews/` (don't edit by hand), and the gallery picks them up. To rebuild locally: `pip install pillow && python scripts/build_manifest.py`.
